# TELECOM SOFT Academy

Функциональный учебный прототип для ВКР Габидуллиной Дилноры Камилжановны, 067-22.
Это собственное приложение для демонстрации обучения; оно не является официальной внутренней системой компании.

## Статус размещения

В репозитории — проверенная локальная версия 0.2 на SQLite. Целевые площадки:
Vercel для сайта/API и Neon PostgreSQL для базы. Миграция PostgreSQL и адаптация
API к Vercel ещё не выполнены; интернет-версия не опубликована.
Порядок подготовки и размещения — [DEPLOYMENT.txt](DEPLOYMENT.txt).
Рабочие данные, секреты и документы ВКР в репозиторий не включены.

## Запуск

Нужен Node.js 24 или новее. Зависимости для работы сервера не требуются.
В полном локальном проекте можно дважды нажать `START_SITE.cmd` в родительской папке и открыть http://127.0.0.1:4173. После клонирования этого репозитория используйте команду ниже.

Из терминала в этой папке:

```powershell
node server.mjs
```

При первом запуске создаётся SQLite-база `data/academy.sqlite`, 6 учебных аккаунтов, 6 курсов, 18 уроков и 24 контрольных вопроса. Есть 8 авторских памяток в базе знаний. Начальные записи о прохождении являются синтетическими и обозначены как демоданные. Повторный запуск сохраняет данные. Версия 0.2 дополняет только неизменённые исходные уроки; правки преподавателя и идентификаторы уроков сохраняются.

## Доступ

На странице входа есть три кнопки демонстрационного входа. Начальные реквизиты:

| Роль | Почта | Начальный пароль |
|---|---|---|
| Сотрудник | student@academy.test | Academy2026! |
| Преподаватель | teacher@academy.test | Academy2026! |
| Администратор | admin (или admin@academy.test) | admin |

Это публичные реквизиты учебных аккаунтов, не секреты рабочей системы. После смены пароля соответствующая кнопка демонстрационного входа потребует обычного входа с новым паролем.

## Реализовано

- Сессионный вход с HttpOnly/SameSite-cookie; scrypt для паролей; истечение сессий и выход; проверка Origin для изменяющих запросов; ограничение неверных попыток входа.
- Роли проверяются на сервере: сотрудник, преподаватель, администратор.
- Каталог, поиск и фильтры, самостоятельная запись и назначение курса.
- Учебные материалы с целями и практикой; сохранение прохождения без дублей.
- Тест после всех уроков; подсчёт на сервере; разбор ответов; повторные попытки и история.
- Демонстрационный сертификат после всех уроков и результата от 75%; сохранение через печать браузера в PDF.
- Отчёты преподавателя по назначениям, прогрессу и лучшему баллу; CSV с защитой от формул в полях.
- Создание курса с первым уроком и контрольным вопросом; редактирование материалов, вопросов, вариантов и объяснений; добавление урока.
- Создание пользователя администратором; профиль, смена пароля с завершением сессий.
- Адаптивные страницы, клавиатурный фокус, подписи полей, мобильное меню.
- Раздельные обзоры: личное обучение сотрудника и состояние учебного центра для преподавателя/администратора. Показатели рассчитываются из текущей базы.
- Практические ответы: сохранение черновика, отправка, проверка преподавателем с оценкой и обратной связью. Отправленный ответ и проверка фиксируются; повторное редактирование не затирает результат. Балл практики показывается отдельно от итогового теста и не меняет условие выдачи сертификата.
- Личные заметки к урокам, сохранённые памятки, поиск по базе знаний, скачивание текста статьи.
- Уведомления о курсах и проверенных работах, отметки о прочтении с сохранением в базе.
- Авторские SVG-иллюстрации: обложки направлений, учебная сцена и узор сертификата. Внешние изображения, шрифты и анимационные библиотеки не загружаются.
- Сертификат с персональными реквизитами, декоративной розеткой и печатью на одном A4 в альбомной ориентации. Доступен отдельный явно обозначенный образец: `/#certificate-preview`.
- ФИО студентки в общем футере добавлено по прямому пожеланию пользователя.

## Проверки и скриншоты

```powershell
npm.cmd ci
npm.cmd run check
npm.cmd test
```

Для браузерной проверки используется установленный Microsoft Edge через Playwright. Если Edge отсутствует, настройте доступный браузер в `tests/verify.mjs`. Runtime приложения не зависит от Playwright.

Оба набора проверок создают отдельные базы и снимки в `test-results/`, не изменяя рабочую базу и иллюстрации ВКР. Основной набор — 20 проверок, набор `verify-workspace.mjs` — 14 проверок новых сценариев, в том числе личных данных, доступа, реального цикла проверки работы, сохранности после перезапуска и экранов 320/390/768/1440 px. Результаты сохраняются в `verification.json` в каждой папке запуска. Для проверки только новых сценариев: `npm.cmd run test:workspace`.

После одобрения пользователем ВКР обновлена под версию 0.2: все 16 её скриншотов пересняты, 5 схем/диаграмм подготовлены. Оригиналы — в `../illustrations/`; Word/PDF с суффиксом «вёрстка» — актуальная редакция. Полный снимок предыдущей работы сохранён в `../backups/`. Отчёты — `../verification/thesis-v2-update.json` и `../verification/thesis-quality.json`.

## Структура

- `server.mjs` — HTTP/API, аутентификация, права, SQLite и оценивание.
- `seed.mjs` — учебные материалы и вопросы.
- `lesson-examples.mjs` — разборы ситуаций и примеры к 18 урокам.
- `learning-content.mjs` — 8 памяток и критерии практических работ.
- `workspace.mjs` — заметки, закладки, работы, проверки и уведомления; дополнительные таблицы SQLite создаются без удаления прежних данных.
- `public/app.js` — клиентские страницы и сценарии.
- `public/workspace.js` — обзор центра, практика, база знаний и новый сертификат.
- `public/illustrations.js` — лёгкие авторские векторные сцены.
- `public/styles.css` — адаптивное оформление и печать сертификата.
- `public/workspace.css` — оформление версии 0.2 и печатный макет A4.
- `data/academy.sqlite` — рабочая база; не включать в открытый репозиторий вместе с реальными данными.

## Переменные окружения и будущее размещение

`PORT` — порт (4173 по умолчанию), `HOST` — адрес прослушивания (127.0.0.1 по умолчанию), `DB_PATH` — путь базы, `COOKIE_SECURE=1` — Secure-cookie для HTTPS. API сверяет Origin с доменом текущего запроса, поэтому отдельный `PUBLIC_ORIGIN` для Vercel не нужен.

Для локального сервера `HOST=0.0.0.0` разрешает доступ с других устройств в сети. Для интернет-размещения выбраны Vercel и Neon. До публикации необходимо перенести SQLite в PostgreSQL и адаптировать HTTP/API к функциям Vercel; одного `HOST=0.0.0.0` для этого недостаточно. Сейчас миграция и публикация не выполнены. Подробности — в `DEPLOYMENT.txt`.

Для резервной копии можно остановить сервер и скопировать папку `data` целиком. Не копируйте только основной SQLite-файл во время записи без согласованного механизма резервирования WAL.

## Границы версии

Прототип содержит учебные записи; реальное внедрение и повышение эффективности обучения не измерялись. Нет интеграции с рабочим HRM/SSO, почтового восстановления пароля, видеохостинга, загрузки файлов, прокторинга, аудита действий и независимой проверки сертификатов. Практика принимается текстом и оценивается преподавателем внутри портала. Изменение содержания не сбрасывает ранее сохранённые результаты — для пересмотра учебных целей следует создать новый курс. Актуальные DOCX/PDF и иллюстрации синхронизированы с этой версией сайта.
